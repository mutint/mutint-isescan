Annotate insertion sequences on a reference genome with ISEScan. A panel on the Import data page's reference tabs runs it after a reference is set or updated, or on demand against the stored reference, and merges what it predicts into the annotation as mobile_element features — what breseq's manual recommends doing with CONVERT-REFERENCE -s, so an IS insertion is called as one MOB rather than two junctions. The merge is a port of breseq's own rule; breseq itself is not needed.

The work runs on the task queue, because ISEScan takes minutes on a bacterial genome, and installing the result re-annotates every mutation in the experiment. Until ISEScan's package is provisioned by tools.txt, the panel says so and offers nothing.
